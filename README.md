# 📱 Sistema Integrado de Aplicações

Este é um aplicativo móvel desenvolvido em React Native que funciona como uma central (launcher) de utilidades. Após passar por uma tela de autenticação, o usuário é direcionado para uma Home que concentra o acesso a quatro miniaplicativos diferentes, simulando a tela inicial de um celular.

## 🚀 O que o aplicativo faz

O projeto integra um fluxo de navegação principal com as seguintes ferramentas e recursos:

* **🔐 Sistema de Contas:** Cadastro e login de usuários com validação de dados e armazenamento local offline utilizando **SQLite**.
* **🧮 Calculadora de IMC:** Ferramenta para calcular e avaliar o Índice de Massa Corporal.
* **🪙 Conversor de Moedas:** Utilitário para conversão de valores entre diferentes moedas.
* **🍔 Sistema de Pedidos:** Tela focada na simulação de escolhas de Fast Food.
* **🪐 Sistema Solar:** Ambiente informativo com a temática espacial.

## 🛠️ Tecnologias Utilizadas

* **React Native / Expo:** Estrutura e desenvolvimento da interface.
* **React Navigation:** Gerenciamento do fluxo de telas (Stack Navigation).
* **Expo SQLite:** Persistência de dados local para gerenciamento das credenciais de acesso.
